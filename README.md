# Pembelajaran JavaScript 🚀

Selamat datang di repositori **Pembelajaran JavaScript**! 🎉  
Repositori ini berisi materi, kode, dan contoh yang dirancang untuk membantu Anda memahami dasar-dasar hingga konsep lanjutan dalam **JavaScript**, bahasa pemrograman yang sangat populer untuk pengembangan web.

---

## 📚 Isi Materi

1. **Dasar-dasar JavaScript**
   - Sintaks JavaScript
   - Variabel dan Tipe Data
   - Operator
   - Struktur Kontrol (if, switch, loop)

2. **Fungsi**
   - Deklarasi dan Pemanggilan Fungsi
   - Fungsi Arrow
   - Parameter Default dan Rest

3. **Manipulasi DOM**
   - Memilih Elemen HTML
   - Event Listener
   - Mengubah Konten dan Gaya Elemen

4. **JavaScript Modern (ES6+)**
   - Let, Const, dan Template Literal
   - Destructuring
   - Modules
   - Async/Await

5. **Pemrograman Berorientasi Objek**
   - Objek dan Kelas
   - Pewarisan
   - Prototype

6. **Penggunaan API**
   - Fetch API
   - JSON
   - AJAX

7. **Proyek Mini**
   - Kalkulator Sederhana
   - To-Do List
   - Fetch Data dari API Publik

---

## 🎯 Tujuan Pembelajaran

- Memahami konsep dasar JavaScript dan cara menggunakannya dalam pengembangan web.
- Membiasakan diri dengan sintaks JavaScript modern (ES6+).
- Menguasai manipulasi DOM untuk membuat halaman web interaktif.
- Membangun proyek mini untuk memperkuat pemahaman.
